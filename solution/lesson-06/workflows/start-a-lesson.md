# Start a lesson

**When:** at the start of every lab.

## Steps

1. Update the course repo: `git pull`.
2. Open `lessons/NN-*/START-HERE.md` and do step 1: run the finished code in
   `solution/lesson-NN/` and check that your numbers match.
3. To build the lesson yourself, do step 2 of START-HERE: copy `starter/lesson-NN` to
   your own folder, start Claude Code there (`claude`), and run `/start-lesson NN`.

## Done when

Your numbers from step 1 match START-HERE, and you can name the modules you'll build, in
order, with the test file for each.
