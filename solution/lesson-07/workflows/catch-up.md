# Catch up on a lesson

**When:** you're behind, or your build won't go green, and the class is moving on.

## Steps

1. Keep your attempt: if your folder is a git repo, commit it.
2. Either start the next lesson from its starter (it already contains every earlier
   lesson's finished code), or copy the modules you're missing from
   `solution/lesson-NN/` in the course repo into your folder (`/catch-up NN` does this
   with you).
3. Run `/verify`.
4. Later, compare your version with the finished one, module by module.

## Done when

`/verify` is green in your folder, or you've moved to the next lesson's starter.
